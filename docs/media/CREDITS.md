# 展示素材

| 文件 | 内容与来源 |
| --- | --- |
| `icon.png`、`guitar-cover.webp` | 本项目的生成式 App 图标与内置练习曲封面。 |
| `banner.png` | 使用内置练习封面绘制的项目展示页封面。 |
| `library.webp` | 资料库的 `RecordPracticeCard` 原生组件在 SwiftUI 宿主中的渲染。 |
| `watch-strum.webp` | `RecordWatchFace` 与 `RecordWatchString` 的拨弦状态，在 SwiftUI 宿主中渲染。 |
| `game-poster.webp`、`rhythm-preview.mp4` | 以真实 `PhoneGameLane`、谱面和评分逻辑渲染的演示，挥腕输入由预设事件模拟。 |

视频使用项目内置的 96 BPM 原创练习曲《随手练习》。击弦声使用 Meta Creative Audio 的 Meta Nylon Guitar 指弹录音，并叠加琴体共鸣。原录音采用 CC0 1.0。详情见 [采样来源与许可](https://github.com/facebookincubator/Meta-open-sound/tree/514c926efecdb3c7812bf00eedf8e5c8d61dd681/systems/instruments/meta-nylon-guitar) 和 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)。
