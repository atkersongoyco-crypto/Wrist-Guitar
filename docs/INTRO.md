# Wrist Guitar 项目介绍

## GitHub 仓库简介

用 Apple Watch 挥腕跟歌。在手表上自由跟弹，或把 iPhone 变成音游舞台，让每次合拍的挥动都有声音和回响。

## 页面首屏

**让手腕也加入这首歌。**

把喜欢的音乐放进 iPhone，戴上 Apple Watch。想自在一点，就在手表上顺着乐句跟弹；想来一局，就让音符落向手机上的蓝线，在合拍的一刻挥腕。

## 内测邀请

Wrist Guitar 有两种玩法。自由跟弹让你边听歌边用手腕加重音。体感音游把舞台移到 iPhone，Apple Watch 做手柄，原曲与击弦声可从手机或手表播放。第一次打开可以先玩内置的 20 秒练习，再换成自己的歌。我们特别想知道，戴上手表时，屏幕上的落点、手里的动作和听见的那一下，能不能自然地对上。
