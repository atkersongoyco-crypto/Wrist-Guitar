# 音频与图像来源

- 20 秒练习曲《随手练习》由项目内的 [生成脚本](../Scripts/generate_demo.py) 制作，速度为 96 BPM。它也是页面视频的背景音乐。
- 指弹、拨片两组吉他采样来自 Meta Creative Audio 的 *Meta Nylon Guitar*，依据 CC0 1.0 使用。项目中的 TourStroke.wav 和 GameStroke.wav 也使用这些录音。GameStroke.wav 同时混入短促的琴身共鸣。[采样说明及原始来源](../Samples/Guitar/Credits.txt)
- App 图标与练习封面为本项目生成。页面图片来自项目资源与原生 SwiftUI 组件渲染。音游视频用模拟挥腕演示手机赛道和计分。
- SwiftUI、Core Motion、AVFoundation 和 Watch Connectivity 随 Apple SDK 提供。Wrist Guitar 是独立项目。
